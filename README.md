# Meridian

A choropleth world map. Countries are colored by a sample measure. Switch the measure, pan and zoom, and open a country for the detail panel.

Open the map:

https://htmlpreview.github.io/?https://github.com/tavashezw/meridian-atlas/blob/main/index.html

Sample figures are rounded and built into the page. They are for exploring the map, not a live statistical release.
